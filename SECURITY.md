# Security Policy

## Reporting Sensitive Issues

Do not open a public issue containing secrets, private model-development details, private evaluations, sealed methods, donor records, student data, school private data, private telemetry, production prompts, infrastructure details, or sealed YOSO-YAi LLC IP.

Use a private maintainer contact path until a formal Foundation security contact is published.

## Public Issue Scope

Public issues may discuss:

- broken links;
- model card wording;
- missing public sections;
- release checklist improvements;
- graph rendering issues;
- public boundary improvements;
- status-language corrections.

Public issues must not include:

- credentials, tokens, or API keys;
- model weights or checkpoints;
- private training corpora;
- private evaluation detail;
- hidden benchmarks;
- production prompts;
- donor, volunteer, student, school, customer, or private partner data;
- security-sensitive NEURONA operational information.

## Supported Scope

This repository is documentation-only. It does not train, host, evaluate, or release models.
