# Evaluation Standard

## Purpose

This standard defines how public evaluation summaries should be written for future reviewed model releases.

## Required Fields

| Field | Requirement |
| --- | --- |
| Evaluation status | Planned, in review, reviewed, released, or not applicable. |
| Evaluation scope | Public-safe description of what was evaluated. |
| Dataset/source basis | Public or reviewed summary only. |
| Metrics | Public metrics only after review. |
| Limitations | What the evaluation does not prove. |
| Bias/risk notes | Known risks and unresolved review needs. |
| Evidence link | Public link or planned status. |

## Boundary Rule

Do not publish hidden benchmarks, private evaluations, sensitive failure logs, private prompts, private telemetry, or source records that expose donor, student, volunteer, customer, or private Foundation data.
